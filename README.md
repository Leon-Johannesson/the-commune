# The Commune

A guild board and shared toolkit for World of Warcraft: Forever. Track item requests, find guild crafters, manage projects, and play daily games together.

Copy the `TheCommune` folder into `_forever_/Interface/AddOns/`, enable the addon, and type `/commune` in game. If you’re updating during a session, use `/reload`.

See the [addon guide and version history](TheCommune/README.md) for commands, features, and troubleshooting.
